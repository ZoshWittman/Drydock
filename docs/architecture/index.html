Core Processing Modules

🎯
Ship Packet Processor
src/modules/processor.ts
Central orchestrator that coordinates all validation modules and determines the final verdict.
  • Generates unique packet IDs
  • Executes modules sequentially
  • Applies fail-closed logic
  • Assembles complete ship packet
🔗
Witness Module
src/modules/witness.ts
Creates cryptographically-verified receipt chain of all operations performed.
  • Records tool invocations
  • Computes SHA-256 hashes
  • Validates chain integrity
  • Tamper-evident audit trail
👁️
Parallax Module
src/modules/parallax.ts
Detects conflicts between PR claims and actual evidence in the diff.
  • Compares claims vs evidence
  • Detects fix without tests
  • Flags refactor conflicts
  • Identifies breaking changes
💥
Blast Radius Module
src/modules/blast-radius.ts
Maps the impact surface: files, packages, routes, and critical areas affected.
  • Analyzes file changes
  • Identifies affected packages
  • Extracts modified routes
  • Calculates impact score
📋
Contracts Module
src/modules/contracts.ts
Enforces project-defined requirements via drydock.yaml contract file.
  • Checks required tests
  • Validates forbidden paths
  • Verifies required docs
  • Fail-closed enforcement
🏗️
Rebuild Module
src/modules/rebuild.ts
Executes isolated rebuild to verify code compiles successfully.
  • Runs npm run build
  • Captures stdout/stderr
  • Records exit code
  • Measures duration
🧪
Test Replay Module
src/modules/test-replay.ts
Re-runs tests in isolation to detect failures and non-determinism.
  • Executes npm test
  • Parses test results
  • Detects divergence
  • Fail-closed on failure

Data & Storage Layer

💾
Database Schema
src/db/schema.ts
SQLite schema initialization and database connection management.
  • Single ship_packets table
  • JSON serialization
  • Indexed queries
  • Local-first storage
🗄️
Repository Pattern
src/db/repository.ts
CRUD operations for ship packets with type-safe interfaces.
  • Save ship packets
  • Retrieve by ID
  • List with pagination
  • Type-safe queries
📊
Type Definitions
src/types/index.ts
Complete TypeScript type definitions for all data structures.
  • ShipPacket interface
  • Module result types
  • Verdict enum
  • Contract definitions

CLI & Entry Points

⌨️
CLI Accept Command
src/cli/accept.ts
Command-line interface for processing PRs and getting binary verdicts.
  • Accepts repo path
  • Processes ship packet
  • Prints summary
  • Exit 0 (MERGE) or 1 (BLOCK)

Key Design Principles

  • Fail-Closed: Unknown states → BLOCK verdict
  • Local-First: No external API dependencies
  • Audit Trail: Complete witness chain for transparency
  • Type-Safe: Full TypeScript coverage
  • Modular: Each module is independently testable
  • Portable: Export ship packets as standalone HTML
